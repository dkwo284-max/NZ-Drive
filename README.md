# NZ Drive — 오클랜드 도심 운전 적응 연습

한국 운전자가 뉴질랜드(오클랜드) 도심 운전에 익숙해지도록 만든 브라우저 게임입니다. 설치·로그인·서버 없이 GitHub Pages 에서 돌아갑니다.

- **4개 목표 트랙**
  - ① 도심 적응 12코스: 좌측통행·우회전, 우회전 vs 맞은편 좌회전(2012 규칙), 로터리, STOP, 횡단보도, 빨간불 좌회전 금지, 버스·T2/T3·클리어웨이, 속도 구간, 스쿨버스
  - ② 면허 준비: 이론 문제은행(57문항, 모의고사 35문항·주제별·오답 복습·영어 병기), 위험 인지(Hazard) 코스, 리스트릭티드 모의 실기(1·2단계, 영어 지시+한국어·음성, 치명 오류/즉시 실격 단순 채점), 표지판 퀴즈, 한국 면허 전환 안내
  - ③ 고속도로·지방·특수: 모터웨이 합류(램프 신호)·추월 후 복귀·출구, 시골길 추월 차선, 1차선 다리, 커브 권장속도·자갈길·가축, 비 오는 날 4초 간격, 철도 건널목, 공사 STOP/GO·임시 속도, 자전거 1.5m, 긴급차 양보
  - ④ 출발·주차·저속: 연석 출발/정차, 언덕 출발(밀림 판정), 평행 후진 주차·3점 회전·언덕 주차(직접 조향, 연석·확인 판정)
- **조작**: 가속 ↑ · 브레이크 ↓/Space · 깜빡이 ← → · 크루즈 C(−/+ 5km/h, 브레이크 시 해제) · 자동 제한속도 A(별 최대 2) · 👀 확인 R · 차선 Q/E · 위험 H · 주차: 핸들 ← →, 기어 G, 완료 Enter
- **화면**: 위에서 본 2D 지도(진행 방향이 위) + 운전석 미리보기(유사 3D) · 시험 준비도 점수 · 약점 리포트(브라우저 localStorage)

## 주의
- 지도는 오클랜드 '느낌'의 가상 배치이며 실제 도로·교차로와 다릅니다. 표지판은 실제 모양을 단순화한 그림입니다.
- 규칙 설명은 NZTA 공식 Road Code 를 요약한 연습용입니다. 실제 운전·시험은 [NZTA Road Code](https://nzta.govt.nz/roadcode/general-road-code)가 기준입니다.

## 구조
`web/` 정적 파일만 있습니다 — `engine.js`(경로·물리·차선·크루즈·규칙 판정·그리기), `scenarios.js`·`scenarios2.js`(코스), `parking.js`(직접 조향 기동), `theory.js`(이론 문제), `quiz.js`, `signs.js`(SVG 표지판), `app.js`(트랙 대시보드·모의 실기·라우팅).
새 코스는 `scenarios.js` 에 `make()` 로 경로·규칙·표지판을 정의해 추가합니다. 로컬 실행: `cd web && python3 -m http.server`.
