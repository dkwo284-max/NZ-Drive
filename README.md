# NZ Drive — 오클랜드 도심 운전 적응 연습

한국 운전자가 뉴질랜드(오클랜드) 도심 운전에 익숙해지도록 만든 브라우저 게임입니다. 설치·로그인·서버 없이 GitHub Pages 에서 돌아갑니다.

- **12개 코스 / 4개 주제**
  - 좌측통행·회전·로터리: 왼쪽 차선 + 우회전, 좌회전 vs 맞은편 우회전, 로터리 직진·우회전
  - Give Way·STOP·횡단보도: STOP 완전 정지, 얼룩말 횡단보도, 빨간불 좌회전 금지
  - 버스·T2/T3·클리어웨이: 버스 차선 시간, T2/T3 인원, 클리어웨이 vs P60 주차
  - 속도·학교·주차: 바뀌는 제한속도(50·30·학교 40), 정차 스쿨버스 20km/h
- **화면**: 위에서 본 2D 지도(진행 방향이 위) + 운전석 미리보기(유사 3D, 다가오는 표지판·신호등)
- **게임 요소**: 위반 순간 멈추고 한국어 교정 설명(Road Code 링크), 점수·별, 표지판 퀴즈 20문항, 진도·약점 대시보드(브라우저 localStorage)
- **조작**: 키보드 ↑ 가속 · ↓/Space 브레이크 · ← → 깜빡이 / 휴대폰은 화면 버튼

## 주의
- 지도는 오클랜드 '느낌'의 가상 배치이며 실제 도로·교차로와 다릅니다. 표지판은 실제 모양을 단순화한 그림입니다.
- 규칙 설명은 NZTA 공식 Road Code 를 요약한 연습용입니다. 실제 운전·시험은 [NZTA Road Code](https://nzta.govt.nz/roadcode/general-road-code)가 기준입니다.

## 구조
`web/` 정적 파일만 있습니다 — `engine.js`(경로·물리·규칙 판정·그리기), `scenarios.js`(코스 정의), `signs.js`(SVG 표지판), `quiz.js`, `app.js`(대시보드·라우팅).
새 코스는 `scenarios.js` 에 `make()` 로 경로·규칙·표지판을 정의해 추가합니다. 로컬 실행: `cd web && python3 -m http.server`.
